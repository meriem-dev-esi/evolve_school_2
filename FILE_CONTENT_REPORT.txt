EVOLVE SCHOOL — SOURCE AND CONFIGURATION FILE CONTENT REPORT
Repository: meriem-dev-esi/evolve_school_2
Application: Evolve Academy public website and student platform (Next.js)

Scope
This report summarizes the purpose and content of source, configuration,
documentation, test, and migration files. It is an inventory, not a copy of
source code. Generated files, dependency folders, local environment files,
Vercel/Supabase local state, build output, diagnostic logs, and binary assets
are excluded. package.json is summarized; pnpm-lock.yaml is listed as the
dependency version lock. One untracked migration is included in a separate
entry so it is not overlooked.
